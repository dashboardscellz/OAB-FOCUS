# OAB Focus SUPER v13

Versão com reorganização profunda da experiência de estudo.

## Principais novidades

- disciplina → capítulo → subassunto, sem resumir o material;
- retorno exato ao ponto de leitura;
- lápis/grifos persistentes por usuário;
- aba **Mais cobrados** baseada em recorrência histórica das provas completas indexadas e sinais do próprio material;
- módulo **Prepare-se** com 30, 60, 90 e 180 dias;
- planejamento adaptativo por tempo disponível, desempenho e proximidade da prova;
- mapas mentais mantidos como revisão visual;
- legislação mantida como consulta secundária;
- layout responsivo para computador, tablet e celular.

## Publicação

A pasta inteira precisa permanecer no repositório. Não envie somente o `index.html`.

Estrutura mínima:

```text
index.html
data/
maps/
database.rules.json
.nojekyll
```
